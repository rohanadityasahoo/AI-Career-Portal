# AI Career Portal

This repository contains the source code and assets for the **AI Career Portal** project, which provides AI‑powered tools for resume analysis, career roadmaps, interview preparation, and job matching.

## Features

- **Resume analysis** using AI models.
- **Career roadmap** generation.
- **Interview simulation** with AI chatbot.
- **Job matching** and application tracking.
- **Report generation** for project documentation.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rohanadityasahoo/AI-Career-Portal.git
   ```
2. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Run the Flask app:
   ```bash
   flask run
   ```
